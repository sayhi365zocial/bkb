# ระบบแสดงตำแหน่งการใช้งาน

ระบบแสดงตำแหน่งการใช้งานบนแผนที่แบบ Interactive โดยใช้ข้อมูลพิกัด GPS

## คุณสมบัติ

- 📍 แสดงตำแหน่งบนแผนที่จากข้อมูลที่ Paste เข้ามา
- 🗺️ ใช้ Leaflet.js และ OpenStreetMap
- 📊 แสดงสถิติจำนวนตำแหน่งและผู้ใช้
- 💬 แสดงรายละเอียดเมื่อคลิกที่ marker
- 🎨 รองรับภาษาไทย
- 📱 Responsive Design

## วิธีใช้งาน

1. เปิดไฟล์ `index.html` ในเว็บเบราว์เซอร์
2. วางข้อมูลในช่อง "ข้อมูลตำแหน่ง"
3. กดปุ่ม "แสดงบนแผนที่"
4. คลิกที่จุดบนแผนที่เพื่อดูรายละเอียด

## รูปแบบข้อมูล

ข้อมูลต้องเป็นรูปแบบ Tab-separated values (TSV) ดังนี้:

```
ชื่อ[TAB]รหัส[TAB]พิกัด[TAB]วันที่-เวลา
```

**ตัวอย่าง:**

```
พิชชาพร มินสิน	EZYtrfpMZRmmnmQd	8.108287, 98.306597	11/11/2025 14:22:10
จิรทีปต์ สนิทวงศ์	EZYwJ8mBCpvHf35o	7.958515, 98.384452	11/11/2025 11:37:30
แอนนิต้า ถิ่นเกาะยาว	EZYpoDZxmp809w8e	8.077405, 98.300473	11/11/2025 08:36:45
```

## ฟีเจอร์

### การแสดงผล
- แผนที่จะ auto-zoom ให้เห็นทุกตำแหน่ง
- แต่ละ marker แสดง:
  - ชื่อผู้ใช้
  - รหัส ID
  - พิกัด (Latitude, Longitude)
  - วันที่และเวลา

### สถิติ
- จำนวนตำแหน่งทั้งหมด
- จำนวนผู้ใช้ที่ไม่ซ้ำกัน

## เทคโนโลยี

- HTML5
- CSS3
- JavaScript (Vanilla)
- Leaflet.js v1.9.4
- OpenStreetMap

## ข้อกำหนด

- เว็บเบราว์เซอร์สมัยใหม่ (Chrome, Firefox, Safari, Edge)
- การเชื่อมต่ออินเทอร์เน็ต (สำหรับโหลดแผนที่)
